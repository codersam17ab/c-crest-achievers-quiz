# C-CREST ACHIEVERS Quiz Game

A two-team web-based question-and-answer quiz application designed for club events.

## Features
- **50 Questions** covering history, science, chemistry, biology, and programming.
- **Two-Team Challenge** with control-passing mechanics.
- **20-Second Countdown Timer** for active turns.
- **Automatic Score & Performance Calculation**.

## How to Run
1. Clone or download this repository.
2. Open `index.html` in any modern web browser, or host via GitHub Pages.
